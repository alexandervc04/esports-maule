ARENA CONTROL - MAPA RAPIDO PARA LA DEFENSA

LOGIN
  PHP -> AV_JP_RM_BE_SP_LOGIN -> ORACLE

10 MANTENEDORES
  GUARDAR -> INSERT / UPDATE + SECUENCIA
  LISTAR -> SYS_REFCURSOR
  ELIMINAR -> DELETE

GESTOR 1 - APERTURA DE TORNEO
  SP_ABRIR_TORNEO
  CRUZA VIDEOJUEGO + PLATAFORMA + SEDE + FORMATO + CATEGORIA + ORGANIZADOR + PATROCINADOR

GESTOR 2 - INSCRIPCION Y ROSTER
  SP_INSCRIBIR_EQUIPO
  -> FN_VALIDAR_CUPOS_TORNEO
  -> SEQ_INSCRIPCION
  -> CURSOR DE JUGADORES ACTIVOS
  -> INSERT ROSTER
  -> TRG_BLOQUEAR_SANCIONADO

GESTOR 3 - FIXTURE
  SP_GENERAR_FIXTURE
  -> CURSOR EXPLICITO OPEN / FETCH / CLOSE
  -> SEQ_PARTIDA

GESTOR 4 - RESULTADOS Y KDA
  SP_REGISTRAR_RESULTADO -> ACTUALIZA MARCADOR Y PUNTOS
  -> TRG_AUDITORIA_MARCADORES
  SP_REGISTRAR_KDA -> DETALLE PARTIDA/JUGADOR

GESTOR 5 - SANCIONES Y PREMIACION
  SP_REGISTRAR_SANCION -> DESCUENTA PUNTOS
  SP_REGISTRAR_PREMIO -> POSICION 1 FINALIZA TORNEO

REPORTES
  SP_REPORTE_DEMANDA_JUEGO
  SP_REPORTE_RANKING_MVP -> FN_CALCULAR_RATIO_KDA
  SP_REPORTE_OCUPACION_SEDES
